# acct-sh v0.2.0

This release implements the reviewed credential, identity, lifecycle, diagnostics,
and delivery remediation. Strict managed operations refuse unknown or inconsistent
profile state, and Git and gh use the shared repository context.

## Changes

- **Resolution and HTTPS:** canonical binding order, root-local markers, worktree
  conflict refusal, host-scoped helper resets, gist mapping and safe failure output.
- **Commit and push:** effective author/committer checks, recorded outgoing identity
  checks, and verification of the actual HTTPS or SSH authenticated account.
- **Lifecycle:** serialized updates, owner-aware locks, rollback on failure,
  symlink/mode-preserving gitconfig writes, shared-secret protection and no backups.
- **Hooks and shells:** global v2 hooks chain existing hooks; Fish has native output;
  failed refresh clears managed variables; `acct_refresh` forces a new resolution.
- **Diagnostics:** measured hook/auth state, unknown whoami exit code 2, missing-path
  hints, subtree rebind and stale node/JS path checks. Wizard EOF/Ctrl-C cancels.
- **Delivery:** reviewed action pins and read-only builds; publish downloads the
  prepared npm and GitHub Packages tarballs without running package scripts.

## Installation

From npm:

```sh
npm install -g acct-sh@0.2.0
acct --version
```

From GitHub Packages, after configuring authentication and the owner scope:

```sh
npm install -g @abdull-ah-med/acct-sh@0.2.0
acct --version
```

Both packages provide `acct` and `git-credential-acct`.

## Upgrading

Run `acct install` once after updating to regenerate scoped includes and v2 hook
shims. Profiles/bindings keep schema version 1. Installation is global by default;
use `acct install --repo` where a local hooksPath overrides it. Existing hooks are
chained, and uninstall restores recorded paths. Move subdirectory `.acct` markers
to the repository root using `acct local set`; subroot markers are now ignored
and reported. Open shells need a directory change or `acct_refresh`.

## Scope and limitations

Client hooks remain bypassable; server-side controls are required for mandatory
policy. Bash prompt refresh happens after commands chained to `cd`; use `acct exec`
or the gh wrapper for immediate resolution. IdentitiesOnly stops agent keys;
keys configured for that host in ~/.ssh/config are still offered — acct verifies
the authenticated account on push. Imported commit histories without local reflog
provenance may be refused when their author differs. Synthetic tests do not verify
real accounts or native OS keychain behavior. Repository environment protection
and registry trusted publishing require external configuration. The download
artifact action retains the reviewer-requested pin TODO.
